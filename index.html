앱 배포 가이드
✅ 이 파일 자체가 완성된 앱입니다!
index.html 하나로 모든 기능이 작동합니다. 아래 두 방법 중 하나로 바로 배포하세요.
방법 1 — Netlify Drop (30초, 회원가입 불필요)
1
이 파일 다운로드
위 Claude 다운로드 버튼 클릭 → 바탕화면에 index.html로 저장
2
Netlify Drop 접속
브라우저 주소창에 아래 주소 입력:
app.netlify.com/drop
3
파일 드래그 앤 드롭
index.html 파일을 Netlify Drop 페이지 영역으로 끌어다 놓기
→ 10초 후 URL 자동 생성!
4
URL 복사해서 공유
생성된 URL을 카카오톡, 이메일로 팀원들과 공유
스마트폰에서 홈화면에 추가하면 앱처럼 사용 가능
예시: amazing-name-123456.netlify.app
나중에 Netlify 회원가입하면 URL을 anesthesia-manual.netlify.app 처럼 바꿀 수 있습니다.
방법 2 — GitHub Pages (무료 영구 도메인)
1
GitHub 무료 가입
github.com → Sign up → 이메일 인증
2
새 저장소 만들기
+ 버튼 → New repository
이름: anesthesia-manual 공개: Public (반드시 선택) README: 체크 후 Create
3
index.html 업로드
Add file → Upload files → index.html 드래그 → Commit changes
4
GitHub Pages 활성화
Settings → Pages → Source: Deploy from a branch Branch: main → Save
5
2~3분 후 URL 확인
https://[내 아이디].github.io/anesthesia-manual
